# 囍 · wedding-invitation

> 红纸一张，囍字两枚，良辰自此定格。
>
> 这一页，是写给每一位见证我们的人的手写信。

**风流倜傥的郎君 ❤ 倾国倾城的娘子**，把从怦然到相守的每一个瞬间，揉进了这一张会动的手绘请柬——纸纹、蜡笔、烟花、蝴蝶，还有隔着屏幕都能听见的倒计时心跳。

在线预览：[https://kesonglab.github.io/wedding-invitation/](https://kesonglab.github.io/wedding-invitation/)

## 换一种方式，诉说同一段故事

把这片红换成你自己的，它便为你的良辰而红。

- **你的眉眼**：`images/couple.webp` / `couple.png`，婚纱照透明底抠图，正压在囍字前。把你们的合照抠干净、压成 webp 放进来，替我们站上这方舞台。
- **你们的童年**：`images/baby-boy.png` / `baby-girl.jpg`，小时候的贴纸头像，交给这两格安放。
- **那些手写的字**：`welcome.png` / `to-our-wedding.png` / `invitation.png` / `xi.png`，舍不得印刷的笔画，都是心迹。
- **散落的小确幸**：`firework-*` / `tulips` / `flower` / `butterfly` / `heart-*` / `dots` / `gold-stroke`，烟花的喧嚣、蝴蝶的缱绻，尽在角落。

- 改你们的姓名、良辰、地址：打开 `index.html`，替换那里的字。
- 改倒计时的终点：打开 `main.js`，找到 `weddingTime`，写进你们的誓约之刻。

## 把它，安放到云端

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main` / 根目录，保存——爱意即刻上线。

## 关于这张纸

- 纯静态，不依赖、不构建，一份 HTML 就是全部。
- 手写的字来自 Google Fonts，需联网方能入口（Shantell Sans + 站酷快乐体）。
- 手机、平板、桌面，皆可细读；若你偏爱安静，它亦懂 `prefers-reduced-motion`。
