# 囍 · wedding-invitation

> 米白的纸，酒红的字，一颗心跳落在两个人的名字之间。
>
> 这一页，写给每一位愿意来见证的人。

在线预览：[https://kesonglab.github.io/wedding-invitation/](https://kesonglab.github.io/wedding-invitation/)

## 这一版的样子

像一封手写的信，也像一张安静的请柬。

底色是米白的纸感（`#F0EBE1`），上下各一道深红（`#7B1818`）轻轻收边，给文字留出一个温柔的框。中文用了**京華老宋体**，横细竖粗，端庄里藏着一点旧时光的书卷气。英文的 `Hi` 与 `Address` 交给花体 **Pinyon Script**，像蘸了墨的钢笔，在纸角落下一句问候。

主视觉是一笔手写书法「爱在日出日落时」，配一对新人的线描留影。图上原本的纸纹被一点点拂去，于是它落进页面里，像是原本就画在那里。姓名之下，一颗心轻轻跳着，不急不缓，刚好是请柬该有的心跳。

页面背后铺了一层极淡的光影，请柬便像一张真正的纸卡片，安安静静地浮在桌面上。

## 你可以改的地方

这是一份可以借用的骨架。换成你们的故事，它便为你们的良辰而留白。

- **姓名、良辰、地址**：都写在 `index.html` 里，逐字替换即可
- **主视觉**：`images/couple-visual.png`，透明底的书法与插画。想换，就放一张同样抠净背景的图
- **字体**：`fonts/` 里是自托管的中文与英文花体，改 `styles.css` 顶部的 `@font-face` 和字体栈就能替换
- **开场白**：那七行中，中间三行是酒红加粗的重点，想换措辞只改文字、别动结构就好

## 在本地打开

没有依赖，也没有构建。一份 HTML 就是全部。

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000

## 放到 GitHub Pages 上

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、根目录，保存。稍等片刻，请柬就在线了。

## 关于字体

中文字体为**京華老宋体**，英文花体为 **Pinyon Script**，都随项目自托管，不依赖外网，也无需联网等字体。中文字体已按页面实际用字做了子集化，体积从三十余 MB 收到 90 KB 上下，翻开是很快的。

## 它懂得克制

- 纯静态，加载快，也好托管
- 手机、平板、桌面都照顾到了，Chrome 与 Safari 皆可细读
- 若你在系统里开启了"减弱动态效果"，页面的入场与心跳会安静下来，只留下内容本身
