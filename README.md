# 囍 · wedding-invitation

> 米白的纸，酒红的字。
>
> 一颗心跳，正落在两个人的名字之间。

在线预览：[https://kesonglab.github.io/wedding-invitation/](https://kesonglab.github.io/wedding-invitation/)

## 它是什么模样

像一封慢慢写成的信，也像一张安安静静的请柬。

底色是米白的纸感（`#F0EBE1`），上下各一道深红（`#7B1818`）轻轻收着边，仿佛替满纸文字压上一枚镇纸。中文用的是**京華老宋体**，横细竖粗，端端正正，偏偏又藏着一缕旧时闺秀的书卷气。英文的 `Hi` 与 `Address` 交给花体 **Pinyon Script**，像蘸过墨的钢笔，在纸角轻盈地落下一句问候。

主视觉是一笔手写书法「爱在日出日落时」，配一对新人的线描留影。图上原本的纸纹被一点一点拂净了，于是它落进页面里，像原本就画在此处，而不是贴上去的。名字下面伏着一颗心，一跳一跳，不慌不忙，恰是请柬该有的那点心慌。

页面背后还铺着一层很淡很淡的光影，请柬便像一张真的纸，安安静静地浮在桌面上。

## 想改成你们的

这是留给你改的骨架。换成你们的故事，它自会为你们的良辰留白。

- **姓名、良辰、地址**：都写在 `index.html` 里，逐字换掉就好
- **主视觉**：`images/couple-visual.png`，透明底的书法与插画。想换，便放一张同样抠净了背景的图
- **字体**：`fonts/` 里是自托管的中文与英文花体，改 `styles.css` 顶上的 `@font-face` 与字体栈，便能替下来
- **开场白**：那七行里，中间三行是酒红的重点，想改措辞，只动文字、别动结构就好

## 想在本地看看

没有依赖，也不用构建。一份 HTML，便是全部。

```bash
python3 -m http.server 8000
```

然后轻轻点开 http://localhost:8000 就好。

## 想放到网上

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、根目录，保存。稍候片刻，请柬便在云端了。

## 关于字

中文字体是**京華老宋体**，英文花体是 **Pinyon Script**，都随项目自托管，不必联网等它慢慢加载。中文按页面用到的字做了子集，体积从三十余 MB 收到 90 KB 上下，翻开是很快的。

## 一点体贴

- 纯静态，轻盈，也好托付给任何一台服务器
- 手机、平板、桌面都照顾过了，Chrome 与 Safari 皆可细读
- 若你在系统里开了"减弱动态效果"，它的入场与心跳都会静下来，只留内容给你
